Changes to Cacti, Spine and the Cacti plugins go upstream through pull requests from the forks listed below. This page walks through one change from start to finish.

Before you start

  • A GitHub account with the fork of the target repository: cacti or spine.
  • A local PHP 8.2 or later for Cacti 1.2.x work.

Steps

  1. Branch from the upstream base branch (1.2.x or develop), not from the fork's copy of it.
  2. Make one focused change and add or extend a test for it.
  3. Sign off every commit: git commit -s.
  4. Open the pull request against the upstream repository and link the issue it fixes.
