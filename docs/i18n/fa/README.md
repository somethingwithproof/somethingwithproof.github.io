# somethingwithproof.github.io

کد منبع https://somethingwithproof.github.io: یک گالری ایستا از مخازن عمومی همراه با صفحات مستندات تولیدشده.

## ساخت

نیازمند Python 3.12 و ابزار خط فرمان گیت‌هاب (`gh`)، بدون هیچ وابستگی شخص ثالث در Python:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

فایل `content/sitemap.json` بخش‌ها، موضوعات و مخازن را تعریف می‌کند. صفحات دست‌نویس در `content/pages/` قرار دارند. صفحات پروژه از فایل‌های README مخازن پس از عبور از یک پاک‌کننده HTML مبتنی بر فهرست مجاز تولید می‌شوند. در صورتی که هر یک از مخازن فهرست‌شده خصوصی باشد یا نسبت کنتراست رنگ تولیدشده به کمتر از 4.5:1 برسد، فرآیند ساخت با خطا متوقف می‌شود.

## بومی‌سازی

اجزای رابط کاربری، ناوبری، جستجو و برچسب‌ها در ۴۵ زبان محلی در مسیر `locales/` (۲۰ زبان رده اول، ۱۵ زبان آفریقایی و ۱۰ زبان آسیایی) ارائه می‌شوند.

- خروجی HTML ایستا به‌طور پیش‌فرض به زبان انگلیسی است و می‌تواند با دستور `python3 build.py --lang <locale>` برای هر زبان محلی ساخته شود.
- هدر سایت دارای یک انتخابگر زبان با پشتیبانی از `/assets/locales/*.json`، تشخیص خودکار زبان مرورگر و پشتیبانی از `dir="rtl"` برای زبان‌های راست‌به‌چپ (`ar`، `ar-EG`، `ar-MA`، `fa`، `he`، `ur`) است.
- بررسی محلی با دستور `python3 -m unittest discover -s tests` انجام می‌شود.

## استقرار و مجوز

فایل `.github/workflows/pages.yml` در هر بار push به شاخه `main` و همچنین به‌صورت روزانه، سایت را ساخته و روی GitHub Pages مستقر می‌کند. به [نسخه انگلیسی README](../../../README.md) و [LICENSE](../../../LICENSE) مراجعه کنید.
