# somethingwithproof.github.io

Исходный код для https://somethingwithproof.github.io: статическая галерея публичных репозиториев с автоматически генерируемыми страницами документации.

## Сборка

Требуется Python 3.12 и GitHub CLI (`gh`) без сторонних зависимостей Python:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

Файл `content/sitemap.json` определяет разделы, темы и репозитории. Страницы, написанные вручную, находятся в `content/pages/`. Страницы проектов генерируются из файлов README репозиториев после прохождения через HTML-санитайзер на основе списка разрешённых тегов. Сборка завершается ошибкой, если любой из перечисленных репозиториев является приватным или если контрастность любого сгенерированного цвета падает ниже 4.5:1.

## Локализация

Элементы интерфейса, навигация, поиск и подписи поставляются на 45 локалях в каталоге `locales/` (20 локалей Tier 1, 15 африканских и 10 азиатских).

- Статический HTML по умолчанию использует английский язык и может быть собран для любой локали командой `python3 build.py --lang <locale>`.
- В шапке предусмотрен переключатель языка на основе `/assets/locales/*.json` с автоматическим определением языка браузера и поддержкой `dir="rtl"` для локалей RTL (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`).
- Локальная проверка выполняется командой `python3 -m unittest discover -s tests`.

## Развёртывание и лицензия

`.github/workflows/pages.yml` собирает и публикует сайт на GitHub Pages при каждом push в ветку `main`, а также ежедневно. См. полную [английскую версию README](../../../README.md) и файл [LICENSE](../../../LICENSE).
