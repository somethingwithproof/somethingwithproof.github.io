# somethingwithproof.github.io

Изворни код за https://somethingwithproof.github.io: статичка галерија јавних репозиторијума са аутоматски генерисаним страницама документације.

## Изградња

Захтева Python 3.12 и GitHub CLI (`gh`), без спољних Python зависности:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

Датотека `content/sitemap.json` дефинише одељке, теме и репозиторијуме. Ручно писане странице налазе се у директоријуму `content/pages/`. Странице пројеката генеришу се из README датотека репозиторијума филтрираних кроз HTML чистач заснован на листи дозвољених елемената. Изградња се зауставља ако је било који наведени репозиторијум приватан или ако однос контраста боја падне испод 4.5:1.

## Локализација

Елементи интерфејса, навигација, претрага и ознаке доступни су у 48 језичких ознака у директоријуму `locales/` (20 Tier 1, 15 афричких, 10 азијских и 3 јужнословенске).

- Статички HTML подразумевано користи енглески језик и може се изградити за било коју подржану језичку ознаку помоћу `python3 build.py --lang <locale>`.
- Заглавље укључује бирач језика заснован на `/assets/locales/*.json`, са аутоматским препознавањем језика прегледача и подршком за `dir="rtl"` за RTL ознаке (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`).
- Проверите локално помоћу `python3 -m unittest discover -s tests`.

## Објављивање и лиценца

Ток рада `.github/workflows/pages.yml` гради и објављује сајт на GitHub Pages при сваком слању на грану `main` и једном дневно. Погледајте [енглеску верзију README](../../../README.md) и датотеку [LICENSE](../../../LICENSE).
