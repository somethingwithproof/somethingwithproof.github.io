# somethingwithproof.github.io

https://somethingwithproof.github.io தளத்திற்கான மூலக் குறியீடு: உருவாக்கப்பட்ட ஆவணப் பக்கங்களுடன் கூடிய பொதுக் களஞ்சியங்களின் நிலையான தொகுப்பு.

## கட்டமைப்பு

மூன்றாம் தரப்பு Python சார்புகள் இல்லாமல் Python 3.12 மற்றும் GitHub CLI (`gh`) தேவைப்படுகிறது:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

`content/sitemap.json` பிரிவுகள், தலைப்புகள் மற்றும் களஞ்சியங்களை வரையறுக்கிறது. கையால் எழுதப்பட்ட பக்கங்கள் `content/pages/` இல் உள்ளன. அனுமதிப் பட்டியல் HTML தூய்மையாக்கி வழியாகச் செல்லும் களஞ்சிய README களில் இருந்து திட்டப் பக்கங்கள் உருவாக்கப்படுகின்றன. பட்டியலிடப்பட்ட எந்தவொரு களஞ்சியமும் தனிப்பட்டதாக இருந்தாலோ அல்லது உருவாக்கப்பட்ட எந்தவொரு வண்ண மாறுபாட்டு விகிதமும் 4.5:1 க்குக் கீழே குறைந்தாலோ கட்டமைப்புகள் தோல்வியடையும்.

## உள்ளூர்மயமாக்கல்

UI கட்டமைப்பு, வழிசெலுத்தல், தேடல் மற்றும் முகப்புச் சீட்டுகள் `locales/` கீழ் 45 மொழியிடங்களில் (20 Tier 1, 15 ஆப்பிரிக்க மற்றும் 10 ஆசிய மொழியிடங்கள்) வழங்கப்படுகின்றன.

- நிலையான HTML இயல்பாக ஆங்கிலத்தில் இருக்கும்; `python3 build.py --lang <locale>` மூலம் எந்த மொழியிடத்திலும் உருவாக்கலாம்.
- தலைப்புப் பகுதி `/assets/locales/*.json` ஆதரவுடன் கூடிய மொழி மாற்றியை வழங்குகிறது; இதில் உலாவி மொழித் தானியங்கி கண்டறிதலும் RTL மொழியிடங்களுக்கான (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) `dir="rtl"` ஆதரவும் உள்ளன.
- `python3 -m unittest discover -s tests` மூலம் உள்ளூரில் சரிபார்க்கவும்.

## பயன்பாட்டு வெளியீடு மற்றும் உரிமம்

`main` கிளையில் செய்யப்படும் ஒவ்வொரு push க்கும் மற்றும் தினமும் `.github/workflows/pages.yml` கட்டமைத்து GitHub Pages இல் வெளியிடுகிறது. [ஆங்கில README](../../../README.md) மற்றும் [LICENSE](../../../LICENSE) ஆகியவற்றைப் பார்க்கவும்.
