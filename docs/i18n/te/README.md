# somethingwithproof.github.io

https://somethingwithproof.github.io కోసం మూల కోడ్: రూపొందించబడిన డాక్యుమెంటేషన్ పేజీలతో కూడిన పబ్లిక్ రిపోజిటరీల స్టాటిక్ గ్యాలరీ.

## బిల్డ్

మూడవ-పక్ష Python డిపెండెన్సీలు లేకుండా Python 3.12 మరియు GitHub CLI (`gh`) అవసరం:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

`content/sitemap.json` విభాగాలు, అంశాలు, మరియు రిపోజిటరీలను నిర్వచిస్తుంది. చేతితో రాసిన పేజీలు `content/pages/` లో ఉంటాయి. అనుమతి జాబితా HTML శానిటైజర్ ద్వారా పంపబడిన రిపోజిటరీ README ల నుండి ప్రాజెక్ట్ పేజీలు రూపొందించబడతాయి. జాబితా చేయబడిన ఏదైనా రిపోజిటరీ ప్రైవేట్‌గా ఉంటే లేదా రూపొందించబడిన ఏదైనా రంగు కాంట్రాస్ట్ నిష్పత్తి 4.5:1 కంటే తగ్గితే బిల్డ్‌లు విఫలమవుతాయి.

## స్థానికీకరణ

UI క్రోమ్, నావిగేషన్, శోధన, మరియు లేబుల్స్ `locales/` క్రింద 45 లోకేల్స్‌లో అందించబడతాయి (20 టియర్ 1, 15 ఆఫ్రికన్, మరియు 10 ఆసియా లోకేల్స్).

- స్టాటిక్ HTML డిఫాల్ట్‌గా ఆంగ్లంలో ఉంటుంది మరియు `python3 build.py --lang <locale>` ద్వారా ఏ లోకేల్‌లోనైనా నిర్మించవచ్చు.
- హెడర్ బ్రౌజర్ భాషా స్వయంచాలక గుర్తింపు మరియు RTL లోకేల్స్ (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) కోసం `dir="rtl"` మద్దతుతో `/assets/locales/*.json` ఆధారిత భాషా స్విచ్చర్‌ను అందిస్తుంది.
- `python3 -m unittest discover -s tests` తో స్థానికంగా ధృవీకరించండి.
