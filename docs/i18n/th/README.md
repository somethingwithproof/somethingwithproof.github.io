# somethingwithproof.github.io

ซอร์สโค้ดสำหรับ https://somethingwithproof.github.io: แกลเลอรีแบบคงที่ของคลังโค้ดสาธารณะพร้อมหน้าเอกสารประกอบที่สร้างขึ้นโดยอัตโนมัติ

## การสร้าง

ต้องใช้ Python 3.12 และ GitHub CLI (`gh`) โดยไม่มีการพึ่งพาแพ็กเกจ Python ของบุคคลที่สาม:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

`content/sitemap.json` กำหนดส่วนต่างๆ หัวข้อ และคลังโค้ด หน้าเว็บที่เขียนด้วยตนเองอยู่ใน `content/pages/` หน้าโปรเจกต์จะสร้างขึ้นจากไฟล์ README ของแต่ละคลังโค้ดที่ผ่านตัวกรองความปลอดภัย HTML แบบรายการที่อนุญาต การสร้างจะล้มเหลวหากมีคลังโค้ดใดในรายการที่เป็นส่วนตัว หรือหากอัตราส่วนความต่างของสีที่สร้างขึ้นลดลงต่ำกว่า 4.5:1

## การรองรับภาษาท้องถิ่น

ส่วนติดต่อผู้ใช้ ระบบนำทาง การค้นหา และป้ายกำกับมาพร้อมกับคำแปล 45 ภาษาท้องถิ่นภายใต้ `locales/` (ภาษาท้องถิ่นระดับ Tier 1 จำนวน 20 ภาษา แอฟริกา 15 ภาษา และเอเชีย 10 ภาษา)

- ไฟล์ HTML แบบคงที่จะใช้ภาษาอังกฤษเป็นค่าเริ่มต้น และสามารถสร้างเป็นภาษาท้องถิ่นใดก็ได้ผ่าน `python3 build.py --lang <locale>`
- ส่วนหัวมีตัวสลับภาษาที่ดึงข้อมูลจาก `/assets/locales/*.json` พร้อมการตรวจจับภาษาของเบราว์เซอร์อัตโนมัติและการรองรับ `dir="rtl"` สำหรับภาษาท้องถิ่นแบบขวาไปซ้าย (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`)
- ตรวจสอบบนเครื่องของคุณได้ด้วย `python3 -m unittest discover -s tests`

## การปรับใช้และสัญญาอนุญาต

`.github/workflows/pages.yml` จะสร้างและปรับใช้ไปยัง GitHub Pages ทุกครั้งที่มีการพุชไปยัง `main` และทำงานเป็นประจำทุกวัน ดูรายละเอียดเพิ่มเติมได้ที่ [README ภาษาอังกฤษ](../../../README.md) และ [LICENSE](../../../LICENSE)
