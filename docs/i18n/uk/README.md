# somethingwithproof.github.io

Вихідний код для https://somethingwithproof.github.io: статичної галереї публічних репозиторіїв зі згенерованими сторінками документації.

## Збірка

Потрібні Python 3.12 і GitHub CLI (`gh`), без сторонніх залежностей Python:

```sh
python3 build.py --fetch   # refresh cache/ from GitHub, then build _site/
python3 build.py           # build from cache/
python3 -m http.server -d _site 8765
```

`content/sitemap.json` визначає розділи, теми та репозиторії. Написані вручну сторінки містяться в `content/pages/`. Сторінки проєктів генеруються з файлів README репозиторіїв, пропущених через HTML-санітайзер зі списком дозволених елементів. Збірка завершується помилкою, якщо будь-який зі згаданих репозиторіїв є приватним або якщо коефіцієнт контрастності кольорів у згенерованому виводі падає нижче 4.5:1.

## Локалізація

Елементи інтерфейсу, навігація, пошук і підписи постачаються у 45 локалях у каталозі `locales/` (20 рівня Tier 1, 15 африканських і 10 азійських локалей).

- Статичний HTML за замовчуванням використовує англійську та може бути зібраний для будь-якої локалі за допомогою `python3 build.py --lang <locale>`.
- У заголовку розміщено перемикач мов на основі `/assets/locales/*.json` з автоматичним визначенням мови браузера та підтримкою `dir="rtl"` для RTL-локалей (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`).
- Локальна перевірка виконується командою `python3 -m unittest discover -s tests`.
